# 🌐 Pricodin Portfolio

A responsive personal portfolio website built with **HTML5** and **CSS3** — designed for a BTech Student & aspiring Web Developer.

---

## 🚀 Live Demo

🔗 **[Click here to view live site](https://pritivish07025.github.io/pricodin-portfolio-/)**

---

## ✨ Features

- Responsive design for Mobile, Tablet & Desktop
- Animated ticker banner
- Services section with hover effects
- Bold quote section
- Project grid layout
- Call-to-action section
- Hamburger menu for mobile

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure & semantic markup |
| CSS3 | Styling, layout & animations |
| Flexbox | Navigation & hero layout |
| CSS Grid | Project section layout |
| Media Queries | Responsive breakpoints |

---

## 📂 Project Structure

```
pricodin-portfolio/
│
├── index.html       → Main HTML file
├── style.css        → All CSS styles

```

---

## 🖥️ Sections

1. **Navbar** — Logo + navigation links + Let's Talk button
2. **Hero** — Big heading + image card + animated ticker
3. **Services** — UI/UX, Web, Brand & Graphic Design list
4. **Quote** — Bold creative quote with inline images
5. **Projects** — Grid layout with project cards
6. **CTA** — Let's Discuss Your Ideas section
7. **Footer** — Brand logo

## ⚙️ How to Run Locally

```bash
# Step 1 — Clone the repository
git clone https://github.com/pritivish07025/pricodin-portfolio-.git

# Step 2 — Open the folder
cd pricodin-portfolio-

# Step 3 — Open in browser
open index.html
```

Or simply **double-click** `index.html` to open in your browser.
